# Suomen Polku — Финский на практике

Одностраничное приложение (React прямо в браузере, без сборки). Прогресс и добавленные слова хранятся в `localStorage` браузера — на устройстве того, кто открыл сайт.

## Как опубликовать на GitHub Pages

1. Зайдите на github.com → **New repository**. Назовите как хотите, например `suomen-polku`. Public.
2. В новом репозитории нажмите **Add file → Upload files** и загрузите `index.html` (файл из этого архива). Важно: файл должен называться именно `index.html` и лежать в корне репозитория.
3. Commit changes.
4. Перейдите в **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, **Branch: main**, папка **/ (root)** → **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://ВАШ-ЛОГИН.github.io/suomen-polku/`

Ссылку можно открывать с телефона, добавлять на домашний экран как обычную страницу — работать будет как приложение.

## Важно про хранение данных

- Прогресс сохраняется в `localStorage` **того браузера и устройства**, на котором открыли сайт. Между разными устройствами/браузерами прогресс не синхронизируется (в отличие от версии внутри Claude.ai, где хранилище привязано к аккаунту).
- Если открыть сайт в режиме инкогнито или очистить данные сайта в браузере — прогресс сотрётся.
- Если это критично, можно позже добавить синхронизацию через простой бесплатный бэкенд (например, Firebase) — но это уже отдельная доработка.

## Как дорабатывать дальше

Два пути:

**Через Claude:** пришлите файл `index.html` (или просто продолжайте в этом чате) и опишите, что изменить — я вношу правки и отдаю обновлённый файл, который останется только перезалить в тот же репозиторий (заменить `index.html` через **Add file → Upload files**, GitHub предложит перезаписать).

**Вручную:** это обычный React-код внутри `<script type="text/babel">`. Можно редактировать прямо на GitHub (кнопка карандаша на файле) или скачать, открыть в любом редакторе кода и залить обратно. Сборка (npm/webpack) не нужна — Babel транспилирует JSX прямо в браузере при открытии страницы.

## Технические детали

- React, ReactDOM и иконки (lucide-react) подключены через esm.sh — CDN, сборка не требуется.
- Шрифты — Google Fonts (Fraunces, Manrope, JetBrains Mono).
- Первая загрузка страницы может занимать чуть больше времени, чем у нативных приложений (браузер транспилирует JSX на лету) — на телефоне это доли секунды, незаметно.
